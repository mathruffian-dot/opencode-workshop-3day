01這三天在做什麼

從「讓 AI 幫你做一件事」，走到「你有一套自己的教學工具」。

我們會沿著一條階梯往上走：地基 → 內部工具 → 外部工具 → 資料庫 → API → 教學應用。
每爬一階，你手上就多一個作品。你不需要每一階都精通——剛好夠用最厲害。
① 我的第一個 Agent 專案
專案骨架、規則檔，以及一張你自己的需求規格卡
② 一份可直接用的教材包
上網抓素材、讀檔生教案、整理檔案，全部本機完成
③ 教材自動產線
教材丟進去，簡報、音訊、逐字稿自己長出來
④ 會存資料的課堂工具
學生在手機上填，資料存得住、看得到
⑤ 把 API 變成自己的工具
拿一把免費金鑰，做一個你自己天天用得到的東西
⑥ 把工具變成學生打得開的網頁
同一個工具加上前端與後端，學生掃 QR Code 就能用

⑤ 和 ⑥ 不是兩個獨立作品，是同一個作品的上下半部：第三天上午先讓它在你自己的電腦裡跑順，下午才把它變成學生打得開的網頁。

開始之前，我們會先問你一件事：你現在教學上最痛的是什麼？想解決什麼問題？
請寫詳細一點。寫不出來也沒關係——第二天和第三天，我們會帶你回頭看第一天寫的東西，那時候你會有完全不同的答案。

02來上課之前

只有四件事，全部免費，不用先裝任何軟體。

  • 帶筆電（Windows 或 Mac 都可以），確認你有管理員權限能安裝軟體
  • 準備一個個人 Gmail。學校的公務帳號常被管理員限制，現場會卡住
  • 如果有你自己的教材（PDF、Word、簡報），帶過來——三天都會拿它當素材
  • 先想一想：你最想讓 AI 幫你解決哪一件事
不需要事先安裝任何軟體，也不需要付費訂閱。三天用到的服務全部有免費方案，而且不用綁信用卡。
先跟你說一聲：第一天晚上會請大家花幾分鐘註冊兩個帳號——Netlify 和 GitHub——然後記得去信箱把兩封驗證信都按掉。
不是要給你功課，是先卡位——學校信箱有時候會延遲幾分鐘才收得到信，而第二天上午兩個都會用到。前一晚弄好，隔天你就不用坐在那邊等信。
註冊完就好，不用做任何設定，其他的第二天上午一起弄。

每個半天一張圖、一個作品。

把工具裝起來，並且搞懂三件最基本的事：專案跟對話有什麼不同、AI 的「腦容量」是什麼、為什麼要先寫規則檔。最後用一套四象限訪談法，把你的痛點變成一張看得懂的需求卡。

Day 2 上午外部工具

讓 AI 伸手到你的電腦以外。我們會走四條不同的通道，而且每一條要的「授權」都不一樣：一條要瀏覽器登入（把教材變成簡報和音訊）、一條完全不用帳號（抓影片字幕）、一條把你做的東西送上網變成一個真的網址、一條把你的作品存進你自己的 GitHub。
過程中你會很清楚地感覺到——很多時候卡住你的不是程式，是授權。這個半天真正要給你的不是四個服務，是那張「通道 × 授權」的地圖：回學校遇到沒教過的服務，你能自己判斷它走哪一條。
第三條和第四條請記得：第二天下午和第三天下午都還會再用到。

Day 2 下午資料庫

先把前兩天的能力收成一個可以重複使用的技能，然後開始讓你的工具「記得住東西」。主線是用 Apps Script 做一個網頁應用程式，資料存進你自己的 Google 試算表——學生掃 QR Code 填，你在試算表裡直接看得到，不用另外學任何後台。
想做「幾十個人同時送、大螢幕即時長出來」的，可以再往上一階去碰 Supabase，那是選配路線，不是每個人都要走。這個半天你也會知道什麼時候根本不需要資料庫。
最後十分鐘是收工存檔：上午已經把 GitHub 接好了，所以這裡只要一句話就把今天的作品存上去。第三天上午我們會從那裡把它拉回來。

關於隱私，第一天我們就會講清楚：免費的 AI 模型，官方文件自己寫明對話資料可能被用來改進模型，其中有些甚至直接寫「請勿提交個人或機密資料」。
所以三天實作有一條底線：只用座號，不用學生姓名。你自己帶來的教材，上課前請先確認裡面沒有學生名字。
一個回學校之後會用到的習慣：先發草稿，確認沒問題才正式發布。
網頁部署服務的免費方案，每個月的「正式發布」次數是有限的，但草稿發布不算次數。所以改一次就正式發布一次，額度會很快用完——用完的時候，你的網站會直接下線，而且訊息不會告訴你原因。
這件事在課堂上不會困擾你（三天用不到幾次），但回學校之後你會自己反覆改，那時候這個習慣就是你的保險。
