GitHub 兩步驟驗證
（2FA）設定指南

剛註冊 GitHub、被要求設 2FA？跟著做，10 分鐘。

回家再做就好約 10 分鐘需要手機AI 幫不了你

先講三件事

一、這個躲不掉

GitHub 對「會放程式碼的帳號」強制要求 2FA。而且 2026-09-02 起，連停用的選項都會消失。早晚要設，不如一次設好。

二、但研習現場可以先跳過

新帳號有 45 天的設定期（再加 7 天寬限）。研習當天看到那個畫面，先按跳過，把時間留給課程，回家再照這份做。

🔴 三、最重要的一件事：復原碼

設定過程會給你一組「復原碼」。GitHub 官方文件寫得很白：
遺失 2FA 且沒有復原碼時，GitHub Support 無法幫你恢復帳號存取。

意思是——手機掉了、又沒存復原碼，那個帳號就永久打不開了，官方也救不回來。
這份指南裡只有這一件事是不可逆的，其他都可以重來。

2FA 到底是什麼

一句話：密碼是「你知道的東西」，2FA 是「你有的東西」。

有人偷到你的密碼，但沒有你的手機，還是進不去。這就是它存在的理由。

⚠️ 它跟研習時打的那組「8 碼」不是同一件事

很多人在這裡搞混：

8 碼（裝置碼）2FA 碼
誰產生的電腦上的 gh 產生你手機上的 App 產生
長相A1B2-C3D4（英數字，有短橫線）6 位純數字，每 30 秒換一次
在證明什麼「這台電腦是我授權的」「現在要登入的是我本人」
什麼時候遇到接 GitHub 到電腦時每次登入 github.com 網頁時
順序上，2FA 是「進門」，8 碼是「進門之後才做的事」。

選哪一種方式

方式建議為什麼
驗證器 App（TOTP）⭐ 選這個GitHub 官方明講「強烈建議用 TOTP，不要用簡訊」。免費、不綁電話號碼、沒網路也能用
簡訊（SMS）不建議換門號就麻煩，出國收不到，官方也不推
安全金鑰不用要另外買實體裝置
Passkey之後再說可以用，但仍建議先有一個 App 當備援

00手機先裝好 App

⭐ 這一步決定你將來換手機會不會出事。

到手機的 App Store／Play 商店搜尋 「Google Authenticator」，安裝。

裝好之後做一件很重要的事：打開 App → 點右上角頭像 → 登入你的 Google 帳號。

💡 為什麼要登入？因為這樣你的驗證碼會備份到 Google 帳號。將來換手機，新手機裝好 App 一登入，全部自動回來。
沒登入的話，手機掉了就只能靠復原碼。
老實說一個代價：這個雲端備份沒有端對端加密。對「放教學材料的 GitHub 帳號」來說這個取捨划算；如果你之後要拿它管理很敏感的東西，再研究別的 App。

不想用 Google 的也可以，任何 TOTP App 都通用（Microsoft Authenticator、Authy、1Password⋯⋯），原理一樣。

01打開 GitHub 的設定頁

電腦瀏覽器登入 GitHub → 右上角頭像 → Settings → 左邊選 Password and authentication

02開始設定

找到 Enable two-factor authentication，點下去。

03掃 QR Code

畫面會出現一個 QR Code。

拿手機打開 Google Authenticator → 點右下角 ＋ → 選 掃描 QR 圖碼 → 對準螢幕。

掃不到？畫面上有 setup key（一長串英數字），可以改用「輸入設定金鑰」手動打進去。

04輸入 6 位數字

App 裡會出現一組 6 位數字（每 30 秒換一次）。把它打進 GitHub 的欄位。

⏰ 看到數字快變色就等下一組，不要打到一半過期。

05🔴 復原碼——千萬不要跳過

輸入正確之後，GitHub 會給你一組復原碼。

注意：它不會自動幫你存，你必須自己主動下載。
請至少存兩個地方，而且不要都存在同一支手機裡——手機掉了就兩個一起沒。
存哪裡怎麼做
☁️ 雲端硬碟下載的檔案丟到 Google 雲端硬碟，開一個資料夾叫「重要帳號」
🖨️ 印出來印一張紙，跟你的重要證件放一起
🔑 密碼管理器有在用的話，存進去

最後勾選 「I have saved my recovery codes」，完成。

換手機怎麼辦

情況怎麼救
App 有登入 Google 帳號（第 00 步有做）新手機裝好 App、登入同一個 Google 帳號 → 驗證碼自動回來
沒登入，但有復原碼用復原碼登入 GitHub，然後重新設定一次 2FA
沒登入，也沒有復原碼❌ 帳號回不去了，官方也救不了。只能重開一個新帳號
第 00 步和第 05 步存在的意義，就是不要走到第三種。

常見問題

6 位數字一直說錯

九成是手機時間不準。TOTP 是依「現在幾點」算出來的，手機時間差幾十秒就會全錯。
手機 → 設定 → 日期與時間 → 打開「自動設定」，然後再試一次。

每次登入都要拿手機打嗎？

登入時勾 「Remember this device」（記住這台裝置），常用的電腦就不用每次打。

手機沒網路能用嗎？

可以。驗證碼是手機自己依時間算出來的，不需要網路——這也是它比簡訊好的原因之一。

一定要用 Google 的 App 嗎？

不用。任何 TOTP App 都相容，換一個也是掃同一個 QR Code。

復原碼用掉了怎麼辦？

每組只能用一次。用掉幾個之後，到 Settings → Password and authentication 可以重新產生一整組新的（舊的會全部失效，記得重存）。

我可以之後把 2FA 關掉嗎？

2026-09-02 之前可以；之後不行了。所以現在設好，反而省事。

設完之後的自我檢查

  • 手機上的 App 有登入 Google 帳號（換手機的保險）
  • 復原碼存了至少兩個地方，其中一個不在手機上
  • 試著登出 GitHub 再登入一次，確認流程你走得順
第三項做完，你就真的會了。
研習隔天要接 GitHub 時，瀏覽器保持登入狀態，現場只剩貼個 8 碼、按一下 Authorize，幾十秒的事。
本指南依 2026-07 查證的 GitHub 官方文件撰寫：2FA 支援 TOTP／簡訊／安全金鑰／Passkey，官方明確建議 TOTP 而非簡訊；復原碼須主動下載、且為完成設定的必要步驟；官方明載遺失 2FA 與復原碼時 GitHub Support 無法恢復帳號存取；新帳號有 45 天設定期與 7 天寬限期；2026-09-02 起不再提供停用 2FA 的選項。Google Authenticator 自 2023-04 起支援 Google 帳號雲端同步（無端對端加密）。
