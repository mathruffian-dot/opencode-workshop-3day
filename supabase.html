Supabase 新手教師
連線指南

從沒用過資料庫的老師，把資料庫接進 OpenCode，用中文操作。

約 15 分鐘免費不綁信用卡不用寫 SQL

怎麼開始：把這個網址丟給你的 AI

這份有一份寫給 AI 看的指令檔。你不用自己讀完整頁——把網址貼給 OpenCode，它會照著做，該問你的時候會停下來問。

照這份做：
https://raw.githubusercontent.com/mathruffian-dot/opencode-workshop-3day/main/skills/supabase-setup/SKILL.md
那份指令檔裡最重要的一條是：建完表格一定要開 RLS，而且要驗證給你看——沒做完不准回報完成。這是唯一會讓學生資料外流的環節，而它預設是關的。
另外它預設會用唯讀模式接上去，只能查不能改，等你熟悉了再放開。

下面的內容是給你自己看的——了解它在做什麼、以及怎麼檢查它做對了。

這是什麼

Supabase 是一個免費的線上資料庫服務。透過 OpenCode 的 MCP 連線，你可以用中文跟 AI 說你要做什麼，AI 就會幫你操作資料庫——建立表格、新增資料、查詢成績、匯入全班名單，不用學 SQL。

傳統做法現在的做法
學 SQL 語法講中文
寫後端程式連接資料庫AI 幫你接
手動建表格、打資料AI 幫你做
每次查資料要寫 script直接問

⚠️ 開始之前，先講三件會出事的事

這三件在你動手之前就要知道，不是讀完再說。

一、不要放學生真名
三天研習的資安底線在這裡也適用：只存座號，不存姓名。
要對照是誰，你自己在本機留一份「座號 ↔ 姓名」對照表就好，那份不要上雲。這樣萬一設定出錯外流，外流的也只是一堆號碼。
本指南所有範例一律用座號。
二、AI 幫你建的表格，預設是「沒有上鎖」的
這是 Supabase 官方文件寫明的行為：
  • 在網頁上用 Table Editor 建表 → 權限保護（RLS）預設開啟
  • 用 SQL 建表 → 權限保護預設關閉
而 AI 幫你建表一律走 SQL。所以你請 AI 建的表預設沒上鎖——任何人拿到你專案的公開金鑰就讀得到裡面的東西。
每次請 AI 建完表，接著問一句： 
剛剛建的表格有沒有開啟 RLS？沒有的話幫我開起來，並且設定成只有我自己讀得到
步驟 5 有完整的檢查方式。
三、免費專案閒置 7 天會被自動暫停
官方規則。放個寒假回來，你會發現資料庫連不上——那不是壞掉，是被暫停了，去 Dashboard 點一下 Restore 就會回來，資料不會不見。
另外免費層同時只能有 2 個 active 專案，要建第三個得先刪掉或暫停一個。

01註冊 Supabase 帳號

  1. 打開瀏覽器，連到 supabase.com
  2. 點右上角的 「Start your project」（有些版面顯示為 Sign in／Sign up，都是同一個入口）
  3. 用你的 Google 帳號或 GitHub 帳號登入
  4. 第一次登入會問一些基本資料，照著填
⚠️ 請用個人 Gmail，不要用學校公務帳號。學校帳號常被管理員限制第三方登入，現場會卡在這一步。不綁信用卡。

02建立專案

  1. 登入後進到 Supabase Dashboard
  2. 點 「New project」
  3. 照下表填，然後點 「Create new project」，等 1～2 分鐘
欄位填什麼說明
Organization用預設的你的所屬組織
Name例如 my-class專案名稱，英數字
Database Password自己設一組，記下來這是直接連資料庫才會用到的密碼。用 AI 操作時完全不會用到它，但重設很麻煩，還是記著
RegionNortheast Asia (Tokyo)離台灣最近
Pricing PlanFree500 MB 資料庫，班級使用非常夠

⭐ 順手把「專案 ID」抄下來

專案建好後，看瀏覽器網址列：

https://supabase.com/dashboard/project/abcdefghijklmnop
                                      └──── 這一段就是專案 ID ────┘

把這串抄下來，下一步要用。它長得像一串隨機英文字母（官方叫 project_ref）。

03安裝 Supabase MCP

這一步是把 Supabase 接進 OpenCode。跟 AI 說一句話就好：

幫我安裝 Supabase MCP，我的專案 ID 是 你剛剛抄下來的那串

它會幫你在 ~/.config/opencode/opencode.json 加入這一段：

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "supabase": {
      "type": "remote",
      "url": "https://mcp.supabase.com/mcp?project_ref=你的專案ID",
      "enabled": true,
      "timeout": 300000
    }
  }
}

三件事說明一下，你會知道自己在裝什麼：

  • ?project_ref=你的專案ID——官方建議的範圍限制。加了它，AI 只能碰這一個專案，碰不到你其他的專案。
  • timeout——OpenCode 預設只等 5 秒，資料庫操作常常不夠，所以放寬到 300 秒。少了這一行，你會常常看到連線逾時。
  • 如果你只想查資料、不想讓 AI 動到資料，網址改成 ...?project_ref=你的專案ID&read_only=true，AI 就只能讀不能寫。新手建議先這樣用一陣子。
⚠️ 設定檔改完要重開 OpenCode，不重開不會生效。
另外，如果你的 opencode.json 裡本來就有 "mcp": { ... } 這一段，不要整個蓋掉，只要把 "supabase" 那一塊加進去。請 AI 幫你合併，它不會弄壞既有設定。

04連線認證

重開 OpenCode 之後，跟 AI 說：

幫我執行 Supabase 認證

它會執行 opencode mcp auth supabase → 瀏覽器自動打開 → 登入 Supabase → 點 「Allow」 → 完成，大約 30 秒。

確認真的成功了

跟 AI 說「幫我列出 MCP 連線狀態」，它會執行 opencode mcp list。你要看到：

● ✓ supabase  connected

看到 ✓ connected 才算成功。如果是別的狀態，把畫面內容貼給 AI，請它幫你看。

05建第一張表，並且把鎖打開

直接用中文說：

幫我在 Supabase 建立一個「班級成績」表格，欄位包括：
- 座號（數字）
- 國文（數字）
- 數學（數字）
請不要有姓名欄位。建完之後幫我開啟 RLS，並確認只有我自己讀得到。

建完之後，自己去確認一次（這一步不要跳過）：

  1. 進 Supabase Dashboard → 左邊選 Table Editor
  2. 找到你剛建的表
  3. 看表格名稱旁邊有沒有 「RLS enabled」或一個鎖頭標記

沒有的話，跟 AI 說「這張表的 RLS 沒開，幫我開起來」。

為什麼要自己看一眼？因為這是唯一會讓學生資料外流的環節，而它預設是關的。花十秒確認，比事後處理外流划算太多。

06你可以這樣用

新增資料

幫我把以下成績加入 Supabase：
1 號 國文85 數學78
2 號 國文92 數學88
3 號 國文78 數學95

查詢

幫我查國文成績大於 80 分的座號
幫我算出全班兩科的平均

匯入 CSV

幫我把桌面上的「成績.csv」匯入 Supabase
匯入前先確認 CSV 裡沒有姓名欄。有的話請 AI 先幫你把那一欄拿掉再匯入。

07常見問題

這要錢嗎？

不用，也不用綁信用卡。免費方案 500 MB 資料庫、1 GB 檔案空間，班級使用非常夠。

連不上了，資料是不是不見了？

多半是被暫停，不是不見。免費專案閒置滿一週會自動暫停。進 Dashboard 點專案，按 Restore 就會回來，資料完整保留。

我的資料安全嗎？

Supabase 傳輸與儲存都有加密，但真正的風險不在 Supabase，在你的表格有沒有開 RLS（見步驟 5）。
另外請務必遵守：不放姓名、不放身分證字號、不放家長聯絡方式。只放座號和成績。

換電腦怎麼辦？

另一台電腦裝好 OpenCode 後，設定檔要再貼一次（步驟 3），然後執行一次 opencode mcp auth supabase 重新登入。資料都在雲端不會不見。

密碼忘了怎麼辦？

Dashboard → 你的專案 → Settings → Database → 重設密碼。
（提醒：用 AI 操作根本不會用到這組密碼，忘了也不影響日常使用。）

我想更保險一點，不要讓 AI 亂改我的資料

步驟 3 的網址加上 &read_only=true，重開 OpenCode。AI 就只能查詢、不能新增或刪除。想改回來再把它拿掉。

下一步

  • 建立你的第一張資料表（記得檢查 RLS）
  • 把班級座號和成績放進去
  • 試著用 AI 查詢和分析

卡住了就直接跟 OpenCode 說：「我卡在 XXX，幫我看看」。

本指南依 2026-07 查證的官方文件撰寫：Supabase 免費方案（500 MB／2 個 active 專案／閒置 7 天暫停）、Supabase MCP（https://mcp.supabase.com/mcp，支援 project_ref 與 read_only 參數）、RLS 預設行為（Table Editor 開啟／SQL 關閉）、OpenCode mcp auth 指令與 MCP 逾時預設值 5000 ms。
