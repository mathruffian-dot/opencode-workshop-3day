簡報技能
使用指南

裝一次，回學校每學期都能用。完全免費，不用綁信用卡。

第三天帶得走的技能安裝約 10 分鐘零 API 金鑰

怎麼開始：把這個網址丟給你的 AI

這份指南有一份寫給 AI 看的指令檔。你不用自己讀完下面全部——把網址貼給 OpenCode，它會照著做，該問你的時候會停下來問。

照這份做：
https://raw.githubusercontent.com/mathruffian-dot/opencode-workshop-3day/main/skills/slide-setup/SKILL.md
那份指令檔裡已經幫你擋掉研習現場實測出來的兩個坑——安裝程式會裝錯資料夾卻顯示成功、用錯終端機會直接崩潰。
所以照著它做就好，這兩件事它會自己先處理掉。

下面的內容是給你自己看的——了解它在做什麼、以及怎麼檢查它做對了。

01先選一包（也可以兩包都裝）

兩包都是「說一句話，AI 讀你的教材做出簡報」，差別在產出的檔案格式。

HTML 互動簡報可編輯 PPT
產出檔案一個 index.html一個 .pptx
怎麼播雙擊，瀏覽器全螢幕PowerPoint 打開
事後改字要請 AI 改PowerPoint 直接改
互動效果✅ 滑桿、前後對比❌
傳給同事 / 學校收檔⚠️ 不是標準格式✅ 就是一般 PPT
還要裝什麼Python（已有）Python ＋ Node.js（已有）
怎麼選：「上課直接播，最好有點互動」→ HTML。
「做完還要改」「要給同事」「學校要收檔」→ PPT。
兩包不衝突，都裝也可以。

02為什麼不用 AI 生的圖？

這兩包是刻意挑的零金鑰版本——底圖用漸層色、圖示用 emoji 和內建圖形。

網路上很多教學會叫你去申請 OpenAI 金鑰，那是完整版。完整版要綁信用卡、要付費，這場研習不走那條路。

真的需要圖怎麼辦？
自己去 Google Gemini 或 ChatGPT 的網頁版生一張，存下來，再請 AI 幫你插進簡報。免費、不用管金鑰。

03先建一個資料夾（這步不能跳）

跟 OpenCode 說：

幫我建立 OpenCode 的技能資料夾

或你自己在 PowerShell 貼這一行：

New-Item -ItemType Directory -Force "$HOME\.config\opencode\skills"
🔴 為什麼一定要先做這步
安裝程式會自己找「技能要裝到哪」，但它的找法是「看哪個資料夾已經存在」。

如果 OpenCode 的技能資料夾還沒被建出來，它會裝到 Claude Code 的資料夾去，然後畫面照樣顯示「✔ 已安裝！」——你會以為成功了，但 OpenCode 永遠找不到這個技能。

這是實測出來的，不是理論。先建資料夾就沒事。

04安裝

跟 OpenCode 說（選你要的那一包）：

幫我安裝 html-slide-builder-lite 這個簡報技能，
repo 是 https://github.com/mathruffian-dot/claude-html-slide-builder-lite
裝之前先確認 ~/.config/opencode/skills 資料夾存在，
用 PowerShell 跑 install.py，不要用 bash

要 PPT 那包就把網址換成 https://github.com/mathruffian-dot/soil-teaching-deck。

⚠️ 不要 clone 到 Google 雲端硬碟裡，同步會咬住檔案。放 C:\Users\你的名字\ 底下就好。

05驗證（不要跳過）

畫面說成功不算數，要看檔案真的在不在。 跟 OpenCode 說：

列出 ~/.config/opencode/skills 底下有哪些資料夾
  • 看到 html-slide-builder-lite 或 soil-teaching-deck → ✅ 成功
  • 沒看到 → 跟 AI 說下面這句
技能沒裝到 OpenCode 的資料夾，
去 ~/.claude/skills 找一下，找到就搬過來

06關掉 OpenCode，重新打開

技能是開啟程式時載入的，不重開不會生效。
很多人卡在這裡——裝好了、位置也對，就是叫不動，原因只是沒重開。

07做第一份簡報

準備好你的教材（Word、PDF、純文字，甚至一段課本內容都行），然後說：

把這份教材做成互動簡報，大概 12 頁

或：

把這份教材做成可編輯的 PPT，用教學版型

做完之後：

  • HTML → 檔案總管裡雙擊 index.html，瀏覽器全螢幕就是投影片
  • PPT → 用 PowerPoint 打開，逐頁看一下有沒有字爆出來

08常見問題

問題怎麼處理
裝好了但 AI 說找不到技能九成是沒重開 OpenCode。還是不行，回步驟 05 確認檔案位置
一堆紅字，出現 cp950AI 用錯終端機了。跟它說「改用 PowerShell 跑」
做 PPT 時說找不到 node第二天教 clasp 時裝過 Node.js。跟 AI 說「幫我確認 Node.js 有沒有裝好」
可以改配色嗎可以，直接說「改成藍色系」「字再大一點」
我想要 AI 生的插圖去 Gemini／ChatGPT 網頁版生好存成圖檔，再說「把這張圖放到第 3 頁」

回學校之後

這兩包裝在你的電腦上，跟這場研習的專案無關——開任何資料夾都能用。

下學期要做課程簡報、期初報告、家長日簡報，打開 OpenCode 說一句話就好。
