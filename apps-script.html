Apps Script ＋ clasp
連線指南

第二天下午做作品④ 用的。讓 AI 直接讀寫你的試算表腳本。

全班主線現場約 15 分鐘免費要用個人 Gmail

這是什麼

Apps Script 是 Google 內建的程式工具，可以直接讀寫你的 Google 試算表。
clasp 是 Google 官方的命令列工具，讓 OpenCode 能幫你寫 Apps Script 程式並直接推上雲端。

結合之後：你講中文 → AI 寫程式 → 自動推到你的 Google 帳號 → 試算表就自動化了。

為什麼不是「AI 給你程式碼、你自己貼上去」

差別在「AI 看不看得到你線上那份程式碼」：

自己複製貼上用 clasp
AI 知道你線上的程式長怎樣嗎❌ 不知道，你得貼給它看✅ 自己 pull 下來讀
改一個地方生程式 → 複製 → 切瀏覽器 → 貼上 → 存檔講一句話，它改完自己推上去
改五次來回貼五次講五句話
程式碼在哪只在雲端也在你電腦上，可以進 GitHub

作品④ 現場一定會反覆調整，這個差別會被放大很多次。

⚠️ 昨晚的功課：先打開 Apps Script API

如果你昨晚已經做了，跳過這段。

  1. 用個人 Gmail 登入 Google
  2. 打開 script.google.com/home/usersettings
  3. 把 「Google Apps Script API」的開關打開
🔴 這個開關要 1–2 分鐘才生效
所以才排在前一晚。
現在才發現沒開？馬上開，然後先去做 L1 那段，等一下再回來做這裡。跟講師說一聲，助教會來看你。

01確認 Node 版本

跟 OpenCode 說：

幫我確認 Node.js 版本

它會執行 node --version。要看到 v22 以上。

  • ✅ 有看到 v22／v24 之類 → 直接跳到步驟 2
  • ❌ 顯示 v20、v18 或「找不到指令」 → 跟 OpenCode 說「幫我安裝 Node.js LTS」，它會處理
第一天裝環境時（00-env-setup 懶人包）就已經裝過 Node 了，所以這一步多半是走個確認。

02clasp 登入

跟 OpenCode 說：

幫我執行 clasp 登入

它會執行 npx @google/clasp login → 瀏覽器自動打開 → 選你的個人 Gmail → 點「允許」→ 看到 Successfully logged in。

為什麼用 npx 不用全域安裝？npx 不用先裝、每次現抓，而且繞開 Windows 的執行原則限制。之後你如果會常用，再請 OpenCode 幫你 npm install -g @google/clasp，直接打 clasp 會快很多。

03確認真的成功了

幫我確認 clasp 登入狀態

看到你的 Gmail 出現就成功了。

卡住的話對照這張表

你看到的意思怎麼辦
admin_policy_enforced你用到學校帳號了執行 npx @google/clasp logout，重來一次改選個人 Gmail
User has not enabled the Apps Script API開關沒開，或還沒生效回上面開開關，等 1–2 分鐘再試
「因為這個系統上已停用指令碼執行」Windows 執行原則跟 OpenCode 說一聲，它會處理
node: 找不到指令沒裝 Node回步驟 1

卡超過幾分鐘就舉手，不要一個人耗——助教會過來。

04做出作品④

登入成功之後，直接用中文說。以下是作品④ 的起手式：

幫我用 clasp 建立一個綁定新試算表的 Apps Script 專案，
試算表名稱是「課堂提問箱」。

然後做一個網頁應用程式：
- 學生用手機打開，可以填「座號」和「想問的問題」
- 送出後資料存進試算表
- 我自己打開網頁時可以看到所有人的提問

做好之後幫我部署，給我網址和 QR Code。
🔒 資安底線照舊：只放座號，不放姓名
這條不因為資料在你自己的 Google 帳號底下就放寬——你等一下就要把網址發給全班，那是一個公開網頁。

05你之後還可以這樣用

幫現有試算表寫自動化

我有一份 Google 試算表，網址是 https://docs.google.com/spreadsheets/d/XXXXX/edit
幫我用 clasp 把它的腳本拉下來，然後寫一個 Apps Script：
自動計算每個座號的總分和平均，把結果寫回試算表

做成儀表板

幫我把這個試算表部署成一個網頁應用，
讓我在瀏覽器看到成績總覽、及格率、各科平均

定時自動執行

幫我在 Apps Script 裡加一個觸發器，
每天早上 8 點自動把試算表資料備份到另一個工作表

06常見問題

要錢嗎？

不用。clasp 是 Google 官方免費工具，Apps Script 也是免費服務（每天有執行次數上限，一般班級用碰不到）。

為什麼一定要個人 Gmail？

學校的 Google Workspace 帳號預設會擋掉第三方工具授權，你會看到 admin_policy_enforced。這個錯誤你自己解不了——要學校的 Workspace 管理員進 Admin Console 把 clasp 的 OAuth Client ID 加白名單。用個人 Gmail 就完全沒這個問題。

clasp 真的卡住了，作品④ 就做不出來嗎？

不會。還有一條退路：請 AI 直接把 Code.gs 和 index.html 的內容給你，你自己開 script.google.com 貼上、按部署。功能完全一樣，只是之後每次改都要重貼一次。

clasp 是效率升級，不是作品④ 的必要條件。卡住就換路，不要耗在上面。

換電腦怎麼辦？

新電腦要：確認有 Node 22+ → 執行一次 npx @google/clasp login。Apps Script API 那個開關是綁帳號的，不用再開。程式碼可以用 clasp 從雲端拉回來。

clasp 跟 Supabase 有什麼差別？

clasp ＋ Apps ScriptSupabase
用途操作 Google 試算表獨立的雲端資料庫
適合成績單、點名表、提問箱多人同時寫入、即時更新
課程定位全班主線進階選配

兩者互補。大部分教學情境試算表就夠——會需要 Supabase，通常是因為「很多人同時送資料」。

我看到的教學指令跟這裡不一樣

clasp v3 改過一些指令名稱（例如 open 改成 open-script）。舊教學可能失效，以官方 github.com/google/clasp 為準，或直接問 OpenCode。
